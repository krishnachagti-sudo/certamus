About

I build the thing that runs. I am a computer science student at SDGI Global University reading B.Tech Honours in AI and ML, and CTO of Arcavon, a student startup building a game-tech platform, where I own the technical direction and most of the code.

That means the practical end rather than the theoretical one: a production deployment holding around 99% uptime, a modular frontend that cut feature time by roughly a third, page loads optimised rather than assumed. React and Next on the front, Node behind it, and enough Python and C++ to not be precious about the language.

Outside that I run the GeeksforGeeks student community on campus and have been a Google Student Ambassador, which between them is a lot of workshops for a lot of people. Side projects are where I test things properly: a customer retention app, a decision simulator, and a generative tool that turns a prompt into usable React components.

Hackathons are the format where all of that is the point. The output either runs or it does not, and there is no version of the argument that saves a build which does not work.
